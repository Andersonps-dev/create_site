# Achados (caixa de entrada)

Dicas encontradas no Instagram, YouTube, sites e conversas. Use `/guardar-achado` para adicionar. Quando um achado virar padrão, mova o conteúdo para o arquivo certo (`checklists/`, `padroes/`, `referencias/sites.md`) e marque aqui como **incorporado**.

Formato:
```
## AAAA-MM-DD — título curto
Fonte: @perfil / link
Resumo: o que é, em 1–3 linhas
Aplicar em: arquivo da biblioteca onde isso entra
Status: novo | incorporado em <arquivo> | descartado (motivo)
```
